# ADR-009 - Implantar a plataforma numa só aplicação Java com SQLite (IA)

>**Estado:** Aceite
>**Data:** 2026-10-29
>**Componentes afetados:** todos

## Contexto

O enunciado pede persistência em SQLite ou em memória e docas e pagamentos simulados. A equipa tem 6 pessoas e orçamento fixo (C8). A disponibilidade é uma das top 3 e o desbloqueio não pode depender de partes que falham (ADR-004). O ADR-005 exige que marcar o evento como processado, fechar a viagem e registar o pedido de cobrança aconteçam numa só unidade de trabalho, e isso toca em três componentes.

## Decisão

- Os 15 componentes correm **numa só aplicação Java (uma JVM)**, com uma API REST arrancada em `lisboa_pedala.Main`.
- Há **uma só base de dados SQLite**, acedida por JDBC. Cada componente tem as suas tabelas, com o prefixo do componente, e não lê nem escreve tabelas de outros.
- Os componentes falam entre si por **chamadas de método** à interface pública de cada um. As restantes classes de cada pacote são package-private.
- Docas, bicicletas e a CLI da app são **simuladores fora do pacote** `lisboa_pedala`, no pacote `simuladores`, e só falam com a plataforma pela API REST.
- Pagamentos e AT são **adaptadores simulados** dentro de Cobrança e Faturação.

## Consequências

- Simples de implantar, de testar e de manter para uma equipa pequena (C8).
- A unidade de trabalho do ADR-005 é uma transação JDBC normal.
- A separação entre componentes depende das fitness functions (ArchUnit) e da visibilidade do Java, e não da rede. Por isso a regra RM6 (nada em `lisboa_pedala` importa `simuladores`) também é verificada.
- Uma falha da aplicação para todos os componentes, incluindo o desbloqueio. As docas guardam os eventos (C3b), por isso não se perdem viagens, mas os pedidos de desbloqueio falham enquanto a aplicação estiver em baixo. É um risco para a disponibilidade.

## Alternativas rejeitadas

- **Separar o desbloqueio numa aplicação própria** - isola o caminho crítico, mas obriga a comunicação entre processos e a mais uma parte a implantar (C8). Fica como evolução se a Monitorização de Disponibilidade mostrar valores abaixo do contrato.
