# ADR-002 - Componentes lógicos iniciais (v1)

>**Estado:** Substituído pelo ADR-003 
>**Data:** 2026-10-26
>**Componentes afetados:** todos

## Contexto

A partir das ações identificadas com a abordagem Actor/Action, é preciso uma primeira lista de componentes para começar a atribuir user stories. Nesta fase sabe-se pouco sobre o sistema, por isso a lista é um primeiro palpite.

## Decisão

Começar com 10 componentes - Viagem, Pagamentos, Faturação, Contas, Mapa, Telemetria, Manutenção, Redistribuição, Relatórios e Histórico.

## Consequências

- Há um ponto de partida para atribuir as user stories e analisar a coesão.
- Viagem, Pagamentos e Contas são nomes de entidades.
- A atribuição das user stories mostrou depois que a US3 (reenvio de eventos) e a US11 (medir estações que desbloqueiam) não têm componente.
